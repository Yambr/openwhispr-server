<objective>
Close F6 (security): unauthenticated requests to authed-token routes currently
populate `owrl:ip:127.0.0.1` buckets BEFORE the auth pre-handler returns 401 —
opening an anonymous DoS vector against the rate-limit storage. Fix per D-06
Option B: tag affected routes with `config.authRequired: true` and have the
IP-tier `onRequest` hook early-return when that tag is set AND `req.user` is
unpopulated.

The fix preserves the Phase 6 D-RL1 DoS shield for auth-OPEN routes (signin,
signup, forgot-password remain shielded by IP-tier pre-auth because they
deliberately leave `authRequired` UNSET).
