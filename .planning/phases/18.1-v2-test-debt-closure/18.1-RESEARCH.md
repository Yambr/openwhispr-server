## 8. Pitfalls (planner must encode as `WHY:`)

1. **Rate-limit ordering preserves auth-OPEN DoS shield.** Skip the IP-tier counter ONLY when `authRequired === true && !req.user`. Auth-OPEN routes (`/api/auth/signin`, `/signup`, `/forgot-password`) leave `authRequired` UNSET → IP-tier fires pre-auth per Phase 6 D-RL1. Inverting this re-opens DoS vector.
2. **Diarization fix scope.** Only `failed` + `cancelled` paths covered by tests. Do NOT also "fix" the 504 path at `diarization.ts:336-340` — it already sends `jobId`. Surgical edit at lines 323-324 only.
3. **AccountClient — i18n key, not JSX.** The subtitle string lives in `apps/web/src/locales/{en,ru}/end-user.json`, NOT in `AccountClient.tsx`. The component reads via `t("end-user:end-user.account.subtitle.body.text")`. Test fixture at line 34 also needs sync. Three files, not one.
4. **Mode-3 linter REJECTS suffixed phase tags.** `tools/lint-cjm-doc.ts:162` regex is `/^@after-phase-\d+$/`. Tags like `@after-phase-19a` will FAIL the linter. See §10 D-1.
5. **Stale-comment edits at `assemblyai.ts:23-26` and `rate-limit.ts:27-30`.** Bundle in the rate-limit commit. Easy to forget.
6. **Phase 15 SECURITY commit range** includes 3 review-fix follow-ups (`f523184`, `508041d`, `0735965`). Excluding them shows an inaccurate "3 HIGH unresolved" picture to the security auditor.
7. **`phase-tag-comments` lefthook** may fire on stale-comment edits if a comment header is mistakenly reformatted. Edit body only.
8. **AccountClient locale RU file** must keep parity — RU subtitle must drop "активных сессиях" (or equivalent) so the GREEN assertion holds in any locale.
9. **`existsSync` guard (D-04) prefers a meaningful error.** Pattern: `if (!existsSync(routePath)) throw new Error(\`source-contract path moved: ${routePath}\`)` before each `readFileSync`. Catches future tree moves.
