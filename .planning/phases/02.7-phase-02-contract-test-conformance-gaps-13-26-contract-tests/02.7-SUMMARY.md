# Phase 02.7: Contract-Test Conformance Gaps (13/26 → 25/26 GREEN)

Phase 02.7 was scoped in CONTEXT to close 13 of 26 contract-test failures left after Phases 02.5+02.6 unblocked the auth surface. Six discrete defects were diagnosed (D-01 OAuth channel-scheme mintBearer, D-02 bearer-invalid envelope hybrid, D-03 A+B check-user lifecycle + lower(email) functional unique, D-04 AUTH_URL collapse, D-05 cert-gen + HTTPS contract-test path, D-06 TDD discipline). Five plans (01–05) landed all six fixes with strict TDD per CLAUDE.md TDD-01b.

When Plan 06 (verification + reverse-patch evidence) ran on 2026-05-09, the D-03A loud-fail signUp() helper from Plan 04 stopped silently swallowing 4xx responses and surfaced a NEW root-cause defect that had been masked under the original 13 failures: Better Auth v1.6.9's default user-id generator emits a 32-character base32-style opaque string, but `users.id` was declared as Postgres `uuid` (SQLSTATE 22P02 on every signup attempt). The fail-loud upgrade was doing exactly what it was designed for — surfacing the masked root cause.

Plan 06 STOPPED rather than auto-fix (verify-only plan; CLAUDE.md scope-boundary rule). Phase 02.7 was effectively put into a multi-phase cascade tail (02.8 → 02.21, 9 numbered decimal phases) where each phase surfaced + atomically closed one defect that the previous fix exposed. Plan 06 was re-run on 2026-05-10 against the post-cascade tree and reaches **25 passed | 0 failed | 1 deliberate skipped (26)**. Plan 07 (this closure) flips 02-HUMAN-UAT.md Item 1 unconditionally, retires the Phase 02.5-05 "scope qualifier" framing, and unblocks Phase 03.
