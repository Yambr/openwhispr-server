# Phase 02.7 Plan 04: D-03 Layer A — Seed signUp() Loud-Fail + Preflight Summary

**Tightens packages/data/src/seed/conformance.ts signUp() to distinguish Better Auth's USER_ALREADY_EXISTS code from any other 4xx (real validation/CSRF/rate-limit/server failure), and adds a fail-fast preflight COUNT(*) check at the end of seedConformanceFixtures that converts the previously silent contract-test failure (13/26 RED with no breadcrumb) into a clear seed-time diagnostic.**

## Accomplishments

- **signUp() distinguishes idempotent duplicate from real failure.** Previously ALL of {400, 409, 422} returned `{created: false}` — masked CSRF rejects, rate-limit responses, validation errors, and OOO server failures. Now only `USER_ALREADY_EXISTS` code OR `/already exists/i` message returns idempotent OK; everything else throws with status + 300-char body slice.
- **seedConformanceFixtures preflight COUNT(\*) at end.** New `SELECT count(*)::int AS n FROM users WHERE lower(email) = 'fixture@conformance.test'` runs after the signUp loop. If 0 rows → throws `seed: preflight failed — fixture@conformance.test row not present after signUp loop`. Catches the case where every signup silently failed but the loop completed without error.
- **Forward-compatible with Plan 02.7-05's migration 0004.** The preflight `lower(email)` query works against both the existing case-sensitive composite unique AND the incoming functional unique index — no follow-up edit needed.
- **Deep-export path exposed.** `@openwhispr/data/seed/conformance` added to `packages/data/package.json` exports map so tests in other packages can import the helpers without bundling.
- **17 unit tests** (RED → GREEN). Coverage on `packages/data/src/seed/conformance.ts`: **100% lines, 100% statements, 100% functions, 96.42% branches** (one branch — the unreachable `default authUrl fallback to "http://api.localhost"` when both opts and env are unset — would require deleting the test's `process.env.AUTH_URL`; left untested as it represents a CI-misconfiguration codepath, not user behavior).
