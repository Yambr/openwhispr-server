    - File purpose: Phase 01.1 image-pin verifier (D-05).
    - Tool choice rationale: `docker buildx imagetools inspect` over `docker manifest inspect` (GA stable, daemon-optional, OCI-native — per RESEARCH.md §Architecture Patterns Tool choice).
    - Bash 3.2 compatibility note (macOS).

    Shell options: `set -uo pipefail` (NOT `set -e` — see RESEARCH.md Pitfall 5; we need the loop to accumulate exit codes).

    Behaviour (concrete sequence):

    1. `COMPOSE_FILE="${COMPOSE_FILE:-docker-compose.yml}"`
    2. `TODAY="$(date -u +%Y-%m-%d)"`
    3. Pre-flight: if `command -v docker` fails → `echo "verify-images: docker CLI not found in PATH" >&2; exit 127`.
    4. Pre-flight: if `[[ ! -f "$COMPOSE_FILE" ]]` → `echo "verify-images: $COMPOSE_FILE not found" >&2; exit 2`.
    5. Image extraction (no `yq` dep, per RESEARCH.md §Parsing strategy):
       ```bash
       grep -E '^[[:space:]]*image:[[:space:]]+' "$COMPOSE_FILE" \
         | sed -E 's/^[[:space:]]*image:[[:space:]]+["'"'"']?([^"'"'"' ]+)["'"'"']?[[:space:]]*$/\1/' \
         | grep -v '^#' || true
       ```
    6. For each extracted image (use `while IFS= read -r image; do ... done < <(extraction)`):
       a. Skip empty lines.
       b. **Input safety guard (T-01.1-01):** if image does NOT match regex `^[a-zA-Z0-9._/:@-]+$` →
          `echo "INVALID-IMAGE $image" >&2; fail_count=$((fail_count + 1)); continue`
          (Use bash `[[ "$image" =~ ^[a-zA-Z0-9._/:@-]+$ ]]` test.)
       c. **Cheap future-dated check:** if `[[ "$image" =~ RELEASE\.([0-9]{4}-[0-9]{2}-[0-9]{2}) ]]` and `[[ "${BASH_REMATCH[1]}" > "$TODAY" ]]` (lexicographic == chronological for ISO dates) →
          `echo "FUTURE-DATED $image (tag date ${BASH_REMATCH[1]} > today $TODAY)" >&2; fail_count=$((fail_count + 1)); continue`
       d. **Network check:** `if docker buildx imagetools inspect "$image" >/dev/null 2>&1; then echo "OK $image"; else echo "MISSING $image" >&2; fail_count=$((fail_count + 1)); fi`
    7. `exit "$fail_count"`

    Initialise `fail_count=0` before the loop.

    `chmod +x scripts/verify-images.sh` after writing.
