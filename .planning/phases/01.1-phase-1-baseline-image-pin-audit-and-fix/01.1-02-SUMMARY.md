# Phase 01.1 Plan 02: GREEN — verify-images.sh + make target Summary

Implements the bash image-pin verifier (`scripts/verify-images.sh`) and the `make verify-images` Makefile target that satisfy the contract pinned by Plan 01's RED self-tests (missing-image detection, future-dated tag pre-check, shell-meta input guard).

## What Was Built

### `scripts/verify-images.sh` (87 lines, executable, 0755)

For each `image:` line in `$COMPOSE_FILE` (defaults to `docker-compose.yml`):

1. **Pre-flight** — exits 127 if `docker` CLI is missing, exit 2 if compose file is missing.
2. **T-01.1-01 input regex guard** — rejects image strings failing `^[a-zA-Z0-9._/:@-]+$` with `INVALID-IMAGE <image>` on stderr; never invokes `docker buildx` for unsafe input.
3. **Cheap future-dated pre-check** — for `RELEASE.YYYY-MM-DD…` tags, lexicographic compare against `$(date -u +%Y-%m-%d)`; emits `FUTURE-DATED <image> (tag date YYYY-MM-DD > today YYYY-MM-DD)` to stderr without any network round-trip.
4. **Network check** — `docker buildx imagetools inspect <image> >/dev/null 2>&1`; OK to stdout, MISSING to stderr.
5. **Exit code** = number of failed images (sum of MISSING + FUTURE-DATED + INVALID-IMAGE); 0 = clean.

Bash 3.2 compatible (macOS system bash) — no `declare -A`, no `mapfile`, uses `set -uo pipefail` (not `-e`) so the loop can accumulate failures.

### `Makefile`

Added `verify-images` to `.PHONY:` list and a tab-indented target:

```makefile
verify-images:
	bash scripts/verify-images.sh
```
