**Sub-task 1a — extend schemas.ts:**
Add 6 new zod schemas:
- TextDeltaChunk: object with type literal 'text-delta', text string.
- ToolCallChunk: object with type literal 'tool-call', toolCallId string, toolName string, args unknown (z.unknown()).
- ToolResultChunk: object with type literal 'tool-result', toolCallId string, result unknown.
- FinishChunk: object with type literal 'finish', finishReason string, usage object having promptTokens number and completionTokens number.
- StreamChunk: discriminated union of the above 4.
- StreamingTokenResponse: object with token string.
- DeepgramStreamingTokenResponse: object with token string. (same shape as AssemblyAI but separate name for grep clarity)
- OpenAIRealtimeTokenResponse: object with clientSecret string AND clientSecrets array of strings (length >= 1, length === 2 when streams=2).
