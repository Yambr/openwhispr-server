## Risks + Mitigations

| Risk | Mitigation |
|---|---|
| Class extends a heritage chain (`extends BaseError extends Error`) | Mitigation: walk only `cls.heritageClauses` looking for `/Error$/` identifier on the direct parent. Indirect chains are out of scope for this regex; document in locker header. |
| Constructor truncates in a helper function, not inline | `ctorTruncatesField` only recognises direct `this.<field> = <expr>.slice(...)` / `truncate(...)`. Helper-based truncation surfaces as a false positive; mitigation: allowlist with `# helper-truncated-in-<helperName>` rationale. |
| Field type is `string \| undefined` | Treat same as `string` for the property check; field must still be truncated in the assigning constructor branch or stay undefined. |
| `private` exemption is wrong if pino somehow serializes private fields | TS `private` is compile-time only; at runtime it's a plain property. Mitigation: Phase 37's fix overrides `toJSON()` as the actual defence; this locker enforces the simpler invariant (visible field name + truncation). Document the limit in the locker header. |
