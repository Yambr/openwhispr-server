## Locked Decisions (Recommended Option B network-alias variant)

### D-01 — Traefik service network aliases

`docker-compose.yml` traefik service block — add aliases under network attachment:
```yaml
traefik:
  networks:
    openwhispr_internal:
      aliases:
        - api.localhost
        - auth.localhost
```

Docker's embedded DNS then resolves `api.localhost` and `auth.localhost` to traefik's container IP for ALL services on `openwhispr_internal`. Symmetric with prod DNS resolution.

### D-02 — contract-test-runner CA trust

Runner image (`packages/contract-tests/Dockerfile` from Phase 02.14) needs to trust the bootstrap-generated cert at `compose/traefik/certs/local.crt`:

Option D-02a: mount cert into runner + set `NODE_EXTRA_CA_CERTS=/certs/local.crt` env var (no Dockerfile change)
Option D-02b: bake into image via `COPY` + `update-ca-certificates`

**Picking D-02a** — simpler, no image rebuild on cert rotation. Mount via compose volume `./compose/traefik/certs/local.crt:/certs/local.crt:ro`.

### D-03 — Runner BACKEND_URL/AUTH_URL → https://api.localhost

`docker-compose.yml` contract-test-runner service environment:
```yaml
BACKEND_URL: https://api.localhost
AUTH_URL: https://api.localhost
NODE_EXTRA_CA_CERTS: /certs/local.crt
```

Drop `AUTH_TRUSTED_ORIGINS_EXTRA: http://api:3000` from runner (still needed by seed; keep there).
