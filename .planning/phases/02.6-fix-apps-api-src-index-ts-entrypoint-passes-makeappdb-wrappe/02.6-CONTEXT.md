# Phase 02.6 — CONTEXT

## Goal

Close the LAST cascade defect: `apps/api/src/index.ts:229-233` passes `makeAppDb()`'s wrapper object `{db, pool}` to `buildAuth`/`buildApp` instead of destructuring `.db`. Better Auth's drizzle adapter then explodes with `TypeError: db.select is not a function` inside `findOne`. The `as never` casts at line 232/233 hid the mismatch from typecheck.

After this phase: `make contract-test` passes 100% end-to-end, Phase 02.5-05 can finalize, `02-HUMAN-UAT.md` Item 1 flips. Also adds a `make clean-stack` helper so repeatable contract-test runs survive secret rotation (Phase 02.5-04 hit a stale-volume mismatch).

## Locked Decisions

### D-01 — Surgical destructure + remove `as never` casts

```ts
// BEFORE (apps/api/src/index.ts:229-233)
const { makeAppDb } = await import("@openwhispr/data/client");
const { buildAuth } = await import("./auth.js");
const db = makeAppDb();
const auth = buildAuth({ db: db as never }) as unknown as AuthLike;
const app = await buildApp({ db: db as never, auth });

// AFTER
const { makeAppDb } = await import("@openwhispr/data/client");
const { buildAuth } = await import("./auth.js");
const { db } = makeAppDb();
const auth = buildAuth({ db }) as unknown as AuthLike;
const app = await buildApp({ db, auth });
```

The `as never` casts must be removed. If typecheck still complains after the destructure, that's a real type mismatch we should NOT silence — investigate the actual signatures of `BuildAuthOptions.db` and `BuildAppOptions.db` and align.

### D-02 — `make clean-stack` helper

Add to `Makefile`:

```make
.PHONY: clean-stack
clean-stack:
	docker compose down -v --remove-orphans
	docker volume ls -q | grep -E '^openwhispr_' | xargs -r docker volume rm
	@echo "Stack volumes cleaned. Run 'tools/bootstrap.sh' to regenerate .env, then 'make build' + 'docker compose --profile default up -d --wait'."
```

Operator-friendly. Avoids the Phase 02.5-04 stale-password-vs-rotated-secret class of errors.
