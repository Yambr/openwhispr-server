# Phase 33 / Plan 04 — Better Auth integration + boot wiring + oauth-state hooks + lookup function rewrite

**Requirement closed (partial):** CRIT-FIX-02 — wires lens into production, replaces SECURITY DEFINER function with token_fp lookup, encrypts the non-Better-Auth credential (`oauth_state.code_verifier`).

## Goal

This is the **big plan** of Phase 33. Five independent integration tasks, each with its own RED→GREEN pair, landed as separate atomic commits:

1. Wire `wrapAdapter` into `apps/api/src/auth.ts` so Better Auth's adapter is transparently encrypted.
2. Add `validateMasterKek()` boot gates in `apps/api/src/index.ts` (after BYOK guard) + `apps/worker/src/index.ts`.
3. Manually instrument the two non-Better-Auth `oauth_state.code_verifier` write sites in `apps/api/src/routes/{auth-callback,desktop-signin}.ts` to encrypt before INSERT and decrypt after SELECT (they use raw `sql` templates — Adapter lens cannot intercept).
4. Replace the migration-0005 `lookup_session_by_previous_token(text)` SECURITY DEFINER function with a Node-side helper that hashes plaintext + queries by `previous_token_fp`. Migration `0019b_drop_lookup_session_by_previous_token.sql` drops the SQL function.
5. End-to-end integration test on real PG + real Better Auth: sign-in / sign-out / password-reset / OAuth callback round-trip + raw-DB ciphertext assertion (bypasses Better Auth's 5-min cookie-cache).

**What fails RED:** Test seeds a session row with `previous_token='plaintext-XYZ'` AND `previous_token_fp=sha256('plaintext-XYZ')` AND the 6 ciphertext sidecars. Calls `lookupSessionByPreviousToken(db, 'plaintext-XYZ')` — module does not exist → RED. Migration test asserts `pg_proc` no longer contains `lookup_session_by_previous_token` function → also RED until 0019b lands.

**What passes GREEN:** Helper implements: `const fp = crypto.createHash('sha256').update(plaintext).digest(); return db.query.sessions.findFirst({ where: eq(sessions.previousTokenFp, fp) })`. Migration 0019b: `DROP FUNCTION IF EXISTS lookup_session_by_previous_token(text); REVOKE …` (idempotent + reversible via .down). Grep callers — replace SQL function invocation with Node helper call. CLAUDE.md Hard Rule 1: the function was created in migration 0005 to support `text` column lookup; under ciphertext storage it cannot work — REWRITE is the correct production fix, not a test workaround.

**Decision recorded in 33-04-DECISIONS.md:** REWRITE chosen over DELETE because the overlap-window contract (AUTH-04 5-min) is preserved by the new helper; deleting the function would break the contract.
