    1a. **HIGH-1 fix — auto-create `litellm` database from migrate runner (covers upgrade path).**

       Edit `packages/data/src/migrate.ts` so the `main()` function, BEFORE running Drizzle's
       `migrate()`, opens a direct (NOT pgbouncer) admin connection to the `postgres` database

       ```sql
       SELECT 'CREATE DATABASE litellm OWNER ' || quote_ident($1)
       WHERE NOT EXISTS (SELECT FROM pg_database WHERE datname = 'litellm')\gexec
       ```

       Equivalent JS (since `\gexec` is a `psql` meta-command, use the two-statement pattern in `pg`):

       ```typescript
       // packages/data/src/migrate.ts — before runDrizzleMigrations()
       async function ensureLitellmDatabase(adminUrl: string, owner: string): Promise<void> {
         const admin = new Pool({ connectionString: adminUrl, max: 1 });
         try {
           const { rows } = await admin.query(
             `SELECT 1 FROM pg_database WHERE datname = 'litellm'`,
           );
           if (rows.length === 0) {
             // CREATE DATABASE cannot run inside a transaction. pg's default
             // single-statement query auto-commits — safe.
             await admin.query(`CREATE DATABASE litellm OWNER ${pgIdent(owner)}`);
             console.log('[migrate] created litellm database');
           } else {
             console.log('[migrate] litellm database already exists — skipping create');
           }
         } finally {
           await admin.end();
         }
       }
       ```

       Where `pgIdent(name)` is a tiny helper that whitelists `[A-Za-z_][A-Za-z0-9_]*`
       (no SQL injection — owner name comes from POSTGRES_OWNER_USER env which bootstrap.sh
       generates). DO NOT use parameterized values — `CREATE DATABASE` does not accept them.

       The admin connection uses `POSTGRES_ADMIN_URL` env (existing Phase 1 pattern for
       migrate's superuser path: `postgres://postgres:${POSTGRES_PASSWORD}@postgres:5432/postgres`,
