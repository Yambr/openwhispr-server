<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .env file → container env | Secrets cross at Compose boot via `env_file`; never via build-args |
| Internet → Traefik (host) | Traefik 80/443 are the only published ports; api/migrate/mailpit unreachable from host |
| migrate (DDL/owner role) → Postgres | Direct on 5432, bypassing PgBouncer; explicit assertion in migrate.ts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-01 | Spoofing/Tampering | Default-secret values shipped in .env | mitigate | entrypoint.sh runs check-default-secrets.cjs BEFORE node main; deny-list match → exit non-zero (Layer 2 finally wired; closes Phase 1 D-08) |
| T-02-02-02 | Elevation of Privilege | Container running as root | mitigate | `USER node` (uid 1000) in Dockerfile runtime stage |
| T-02-02-03 | Information Disclosure | Secrets baked into image layers | mitigate | env_file at runtime only; .dockerignore excludes .env*; no ARG SECRET=... directives |
| T-02-02-04 | Tampering | DDL through PgBouncer transaction-mode (corrupted migrations) | mitigate | migrate.ts asserts URL hostname != pgbouncer; uses DATABASE_URL_OWNER → postgres:5432 |
| T-02-02-05 | Information Disclosure | mailpit exposed in production | mitigate | profiles: [dev] — never instantiated by `docker compose up` (default profile only) |
| T-02-02-06 | Denial of Service | docker stop hangs on grace period | mitigate | entrypoint.sh `exec "$@"` ensures Node receives SIGTERM directly |
</threat_model>
