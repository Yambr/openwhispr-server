## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GHA runner → docker daemon | CI environment compromise risk; runner is ephemeral and isolated |
| Test runner → real backend | All assertions are observational — tests do not have admin access to the backend they assert against |
| fixture-idp → API callback | Test-only IdP must not be reachable in production (profile gating) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06-01 | Spoofing | fixture-idp shipped to production by accident | mitigate | profiles:[contract-test] in compose; production `docker compose up` never instantiates; documented in compose comment |
| T-02-06-02 | Tampering | Conformance test passes locally but fails against real deploy | mitigate | Tests use BACKEND_URL only; no in-process app.inject; CI runs against the same docker compose stack operators run |
| T-02-06-03 | Information Disclosure | Failed test logs leak secrets via compose logs artifact | mitigate | Test fixture secrets are non-sensitive (test-PW-12345!); CI uses CI_MASTER_KEK secret which never echoes to artifact (env_file pattern keeps it out of stdout) |
| T-02-06-04 | Denial of Service | Flaky tests block PRs | mitigate | retry disabled (vitest.config.ts) so flakes fail loudly; per Phase 0 lint-tdd policy, root cause must be fixed not retried |
| T-02-06-05 | Elevation of Privilege | branch-protection.json drift vs actual GitHub state | mitigate | Phase 0 self-test compares the file vs `gh api` output; this plan adds contract-test to the file but does not bypass the self-test |
