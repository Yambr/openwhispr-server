# Plan 32-02 — 128-case property test (real PG testcontainer)

**Status:** ready
**Depends on:** 32-01
**File:** `packages/data/src/__tests__/rls-fail-closed.property.test.ts`
**Atomic commits:** 1 RED + 1 GREEN (GREEN may collapse to a single commit if 32-01 already made the test pass — then this plan ships a single commit affirming GREEN).

## Goal

Prove fail-closed semantics across **all 16 tenant-scoped tables × 4 ops (SELECT, INSERT, UPDATE, DELETE) × 2 contexts (with / without `app.tenant_id` GUC) = 128 cases** on a real PG 17 testcontainer.

## Approach

Single boot via `bootMigratedPostgres({ withPgPartman: true })`. After migrate, seed 2 tenants and (where the per-table FK + NOT NULL shape allows) 1 row per tenant per tenant-scoped table.

Some tables have additional NOT NULL FK constraints beyond `tenant_id` (e.g. `messages.conversation_id`). The seed helper builds a per-table row factory keyed by table name. Tables that cannot be seeded without complex fixture setup (e.g. `audit_log` which is partitioned and write-only via `pgcrypto` UUIDs) get seeded with a minimal valid row using `openwhispr_owner` (BYPASSRLS).

Connect as `openwhispr_app`. For each of the 128 cells, assert per the matrix below.

## Expected matrix

| op | with context (tenant A's UUID) | without context (GUC NULL) |
| --- | --- | --- |
| SELECT | `rowCount === 1` (returns tenant A's row, not tenant B's) | `rowCount === 0` (silent-deny) |
| INSERT | succeeds (1 row affected) | raises PG `42501` |
| UPDATE | `rowCount === 1` | `rowCount === 0` |
| DELETE | `rowCount === 1` | `rowCount === 0` |

UPDATE/DELETE without context are not raises; PG reduces target set via USING to 0 rows. The fail-closed property is that **no row of any other tenant is visible or mutable** — verified by SELECT-after asserts.

Cross-tenant containment also asserted: with context=A, SELECT returns A's row only; INSERT with `tenant_id=B` raises (WITH CHECK fails).

## RED

INSERT without explicit `set_config` succeeds (binds default).

Commit RED: `test(32-02): RED — 128-case property test fails on pre-migration fail-open posture`.

## GREEN

No production-code change. The migration from 32-01 makes the test pass.

Commit GREEN: `test(32-02): GREEN — 128-case property test confirms fail-closed posture across 16 tenant-scoped tables`.

## Decisions

- **D-1:** `audit_log` parent INSERT routes to child partition by `created_at` timestamp; the seed row uses `now()`. RLS WITH CHECK applies on the parent.
- **D-2:** `usage_rollup_daily` row needs `(tenant_id, day, model_id)` PK; seed uses `current_date` and `'phase-32-test-model'`.
- **D-3:** `messages` requires `conversation_id` FK; seed creates conversation first.
- **D-4:** For tables where INSERT requires extra columns we don't already seed, the INSERT test cell uses `INSERT INTO <table> (tenant_id, ...) SELECT new_id, ...` builders parameterized per table. A helper map per-table holds (cols, values).
