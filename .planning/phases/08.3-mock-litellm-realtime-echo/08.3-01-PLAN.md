# Plan 08.3-01: mock-litellm `/v1/realtime` echo handler + Run 4 plateau

## Goal

Land a tiny Fastify WebSocket route in `compose/mock-litellm` that accepts the k6 realtime-ws flow handshake and echoes one frame, then run the 30-min mock plateau (Run 4) to produce a complete 4-endpoint p95 baseline for Plan 08-08.

## Tasks

### Task 1 — Add `@fastify/websocket` dep + RED test

**Steps:**

1. Add `@fastify/websocket` (^11.x — Fastify 5 compatible per CLAUDE.md version-compat matrix) to `compose/mock-litellm/package.json` dependencies. Add `ws` (^8.x) to devDependencies for the test client.
2. Run `pnpm install` from repo root.
3. Write `compose/mock-litellm/src/realtime.test.ts` (RED):
   - Spin up a Fastify app, register the not-yet-implemented `realtimePlugin` (import will fail until Task 2).
   - Open a `ws://localhost:<port>/v1/realtime` connection from `ws` library client.
   - Send `JSON.stringify({type:"session.update"})`.
   - Assert: client receives exactly one message frame within 100ms; the frame is JSON-parseable with `event.type === "session.created"` and `event.session.id` starts with `mock-`.
   - Assert: server does NOT close the socket — the client closes (mirror k6 flow contract).
   - Run `pnpm --filter @openwhispr/mock-litellm test --run realtime` — confirm RED.
4. **Commit:** `test(08.3-01): RED for mock-litellm /v1/realtime echo handler`

**Exit criterion:** RED test fails on import or on missing event.type.

### Task 2 — Implement `realtimePlugin` + register in server.ts (GREEN)

**Steps:**

1. Write `compose/mock-litellm/src/realtime.ts`:
   ```ts
   import { randomUUID } from "node:crypto";
   import fastifyWebsocket from "@fastify/websocket";
   import type { FastifyInstance } from "fastify";

   export async function realtimePlugin(app: FastifyInstance): Promise<void> {
     await app.register(fastifyWebsocket);
     app.get("/v1/realtime", { websocket: true }, (socket /*, req */) => {
       socket.once("message", () => {
         const event = {
           type: "session.created",
           event_id: randomUUID(),
           session: { id: `mock-${randomUUID()}` },
         };
         socket.send(JSON.stringify(event));
         // Do not close — client (k6 flow) closes with code 1000 after receipt.
       });
     });
   }
   ```
2. Register in `compose/mock-litellm/src/server.ts`: `await app.register(realtimePlugin);` after existing routes.
3. Run `pnpm --filter @openwhispr/mock-litellm test --run` — confirm GREEN, all existing tests still GREEN.
4. Run `pnpm --filter @openwhispr/mock-litellm test:coverage realtime` — confirm coverage ≥ 90/90/90/90 on `realtime.ts`.
5. **Commit:** `feat(08.3-01): add /v1/realtime echo handler to mock-litellm`

**Exit criterion:** RED test from Task 1 now GREEN; full mock-litellm vitest suite GREEN; coverage gate passes.
