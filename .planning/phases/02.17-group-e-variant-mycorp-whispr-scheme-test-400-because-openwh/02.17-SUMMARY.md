# Phase 02.17: OPENWHISPR_PROTOCOL comma-list + mycorp-whispr — Summary

Closes Group E variant cascade tail (1 oauth-redirect contract test, mycorp-whispr scheme, returning HTTP 400 since Phase 02.13). Root cause was twofold: (a) `apps/api/src/lib/scheme-allowlist.ts:74` accepted `OPENWHISPR_PROTOCOL` only as a single override scheme (not a list), and (b) the bootstrapped `.env` shipped `OPENWHISPR_PROTOCOL=openwhispr` which overrode the docker-compose fallback. Fix is mechanical and atomic: parse the env var as comma-separated, set the contract-test default to `mycorp-whispr` at all three layers (compose, .env.example, .env). Builtin schemes (`openwhispr`, `openwhispr-dev`, `openwhispr-staging`) are unchanged — they live in `BUILTIN_SCHEMES` and are always allowed regardless of the env override.

## Defect → fix narrative

**Symptom (Phase 02.16, 1 failing oauth-redirect test):** `oauth-redirect.test.ts` parametrises 4 schemes (the 3 builtins + `mycorp-whispr` via `OVERRIDE_SCHEME = process.env.OPENWHISPR_PROTOCOL ?? "mycorp-whispr"`). The mycorp-whispr hop returns 400 with `"scheme is not in the configured allow-list"` because the api container env had `OPENWHISPR_PROTOCOL=openwhispr` (the original .env.example default), so the override slot was occupied by the (already-builtin) openwhispr name and `mycorp-whispr` never made it into the allow-set.

**Diagnosis (Class b — env wiring + parser shape):** Two layers needed change to truly close this:

1. **Parser shape** — `scheme-allowlist.ts:74-77` (pre-fix):
   ```ts
   const override = process.env.OPENWHISPR_PROTOCOL?.trim();
   if (override && override.length > 0) {
     allowed.add(override);
   }
   ```
   A single `add(override)` call cannot register multiple custom schemes. Operators with N custom callback schemes had to fork the source. Extending to a comma-list is backwards-compatible (a single value parses as a one-element list) and matches the `AUTH_TRUSTED_ORIGINS_EXTRA` pattern already used in `apps/api/src/auth.ts`.

2. **Env value** — three layers needed alignment:
   - `docker-compose.yml:312` — fallback when env is unset
   - `.env.example:72` — checked-in default that bootstrap copies into operator's `.env`
   - `.env` (gitignored, on-disk) — actual runtime value (re-running bootstrap preserves operator-set values, so an existing `.env` won't be regenerated)

**Fix shape (D-01 + D-02 + D-EX):**
- `scheme-allowlist.ts` — parse `override.split(",").map(trim).filter(Boolean)` into the allow-set.
- `docker-compose.yml` — change fallback from `openwhispr` to `mycorp-whispr` (BUILTIN covers the rest).
- `.env.example` — change default value from `openwhispr` to `mycorp-whispr` + refresh comment to document the comma-list contract.
- `.env` (local, gitignored) — manually updated to `mycorp-whispr` so this run picks it up.

Production operators set their own scheme(s) — they don't need `mycorp-whispr` in production. The default registers it because it's the contract-test profile's marker scheme; production operators always override.
