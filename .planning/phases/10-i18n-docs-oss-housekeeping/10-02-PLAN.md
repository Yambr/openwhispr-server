Target negotiation flow:
1. `apps/web/src/middleware.ts` (Edge) reads cookies().get("NEXT_LOCALE"); falls back to accept-language-parser on Accept-Language header; sets request header `x-locale: en|ru`.
2. `RootLayout` (RSC) reads `headers().get('x-locale')`; passes to `getServerI18n(lng)`.
3. Layout sets `<html lang={lng}>` and serializes the matching resource snapshot to client.
4. `/api/locale` POST `{locale: 'en'|'ru'}` sets `NEXT_LOCALE` cookie (httpOnly: false, SameSite: Lax, 1y).
5. Language switcher component issues fetch + router.refresh().

Resource layout (already exists for en; create ru mirror):

- admin.json (167 lines) — includes audit-log action label keys per research §audit-not-translated
