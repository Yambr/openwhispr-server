## Engineering Discipline (constitutional, non-negotiable)

> All work in this plan MUST conform to `.planning/DISCIPLINE.md` and PROJECT.md § Engineering Discipline.
>
> Hard rules:
> 1. **Strict TDD** — RED -> GREEN -> REFACTOR; tests in the SAME atomic commit as code.
> 2. **Coverage >= 90/90/90/90** on the diff (lines / branches / functions / statements).
> 3. **E2E mandatory** — if this plan touches a wire surface, an `tests/e2e/` test boots `docker compose` and round-trips it.
> 4. **No mocks of internal logic** — mocks only at process / network boundaries.
> 5. **Real services** — testcontainers for DB-touching code; verification refuses to pass while Docker is down.
>
> The gsd-verifier agent enforces these and will report `gaps_found` if any rule is violated.


<objective>
Wire Vitest 4 + Stryker 9 against pre-created skeleton workspaces (`apps/api`, `packages/{auth,data,litellm-client,contract-tests,i18n}`). Purpose: Coverage and mutation gates are constitutional (TEST-COV-01, TEST-MUTATION-01). Wiring them late = wiring them broken. The Vitest-4 nested threshold-keys footgun (RESEARCH Pitfall 1) is the single highest-risk silent-breakage trap; this plan establishes the correct shape from commit #1.
Output: A test/coverage/mutation harness that runs end-to-end against placeholder code and is ready for Phases 1-3 to swap in real implementations.
</objective>
