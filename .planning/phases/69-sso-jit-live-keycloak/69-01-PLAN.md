| env -> boot | operator-supplied OIDC_*_MAPPING JSON crosses into the process at boot |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-69-01 | Elevation | resolveJitDecision role assignment | mitigate | exact-match OIDC_ROLE_MAPPING only (no regex); OIDC_DEFAULT_ROLE=null rejects unmapped groups (mode 3) |
| T-69-02 | Spoofing | tenant claim | mitigate | tenant resolved only against operator OIDC_TENANT_MAPPING; unknown value => forbidden_unknown_tenant (mode 2); no auto-tenant-provisioning |
| T-69-03 | Tampering | malformed OIDC_*_MAPPING JSON | mitigate | validateJitBoot fails fast (exit 78) at boot; never silently disables JIT |
| T-69-04 | DoS | crafted claim shape | accept | resolver coerces defensively and returns invalid_oidc_profile (mode 7); no unbounded work |
</threat_model>
