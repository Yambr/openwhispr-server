# Plan 02.1-01 — `inject-workspace-packages: true` + validation

## Tasks

### Task 1 — Add `inject-workspace-packages: true` to `pnpm-workspace.yaml`

Edit `pnpm-workspace.yaml`, add `inject-workspace-packages: true` as a top-level key (sibling to `packages:` and `allowBuilds:`).

### Task 2 — Regenerate lockfile if needed

Run `pnpm install --frozen-lockfile`. If it fails (lockfile mismatch from the config change), run `pnpm install --no-frozen-lockfile` once and capture the lockfile delta.

### Task 3 — Validate D-03 matrix

Run, in order, stopping at first failure with diagnostic captured to a temp file:

```bash
pnpm typecheck            # workspace resolution sanity
pnpm test                 # all workspace unit tests
docker buildx build -f apps/api/Dockerfile -t openwhispr-api:phase-02.1 .
docker compose --profile default up --wait --wait-timeout 240
docker compose --profile default down -v
```

If anything fails: fall back to variant B (multi-stage Dockerfile rewrite without `pnpm deploy`) — this becomes a follow-up plan 02.1-02.

### Task 4 — Commit

Single atomic commit (`fix(02.1): inject-workspace-packages for pnpm v10 deploy compat`) covering `pnpm-workspace.yaml` + `pnpm-lock.yaml`. Body must include:
- Why (pnpm v10 default change, ERR_PNPM_DEPLOY_NONINJECTED_WORKSPACE)
- Validation evidence (D-03 matrix outcomes)
- Reference to Phase 01.1 Plan 05 unblock

Separate follow-up commit for `02.1-01-SUMMARY.md`.
