## Locked Decisions

### D-01 — Traefik forwardedHeaders.trustedIPs on websecure

`compose/traefik/traefik.yml` websecure entrypoint:
```yaml
websecure:
  address: ":443"
  http:
    tls: {}
  forwardedHeaders:
    trustedIPs:
      - 172.16.0.0/12  # docker default bridge network range
      - 10.0.0.0/8     # additional in-cluster ranges
      - 192.168.0.0/16 # additional in-cluster ranges
  transport:
    ...existing
```

**Important:** This trusts XFF only from these private ranges. External clients (real internet IPs) are NOT trusted; their XFF headers continue to be stripped by Traefik. So this is safe production-side AND enables in-cluster contract-test.

Verify the actual openwhispr_internal subnet via `docker network inspect openwhispr_internal | jq '.[0].IPAM.Config[0].Subnet'` to confirm it falls within the chosen ranges.
