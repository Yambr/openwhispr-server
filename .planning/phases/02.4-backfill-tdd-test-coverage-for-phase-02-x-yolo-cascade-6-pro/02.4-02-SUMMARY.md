## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Dockerfile comment lines satisfied the `pnpm deploy` negative-match**
- **Found during:** Task 1 verification (first vitest run failed 1/8).
- **Issue:** The plan's regex `/pnpm\s+(?:--\S+\s+)*deploy\b/` matched three `#`-comment mentions of historical `pnpm deploy` in the Dockerfile rationale header (lines 7, 8, 14). The intent of the assertion is "no actual `RUN pnpm deploy`" invocation, not "the string never appears in the file" — comments documenting why the project does NOT use `pnpm deploy` are valuable and must remain.
- **Fix:** Added a one-time pre-filter that strips `#`-prefixed lines before applying the negative match (`dockerfileCode = dockerfile.split("\n").filter((l) => !/^\s*#/.test(l)).join("\n")`). The other Dockerfile assertions (positive `FROM ... AS ...`, `--node-linker`, `--filter`) target RUN/FROM directives that are never commented out, so they continue to use the raw `dockerfile` string.
