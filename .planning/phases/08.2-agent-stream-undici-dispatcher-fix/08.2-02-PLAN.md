# Plan 08.2-02: Replace undici.fetch with chatCompletionsStream in agent/stream.ts

<objective>
Swap the inline `undici.fetch` call in `apps/api/src/routes/agent/stream.ts` for the new `deps.litellm.chatCompletionsStream` method delivered by Plan 08.2-01. Convert the upstream Node `Readable` body to a Web `ReadableStream` via `Readable.toWeb` so `sseToNdjson` continues to work unchanged. Map `LitellmUpstreamError` from the client to the existing `endWithFinish(raw, "upstream_error")` path; drop the inline `!upstream.ok` check. Preserve the hijack-before-await ordering, the abort-on-client-disconnect contract, and the `x-litellm-call-id`-only-to-logs invariant.

Purpose: Eliminate the `undici.fetch` failure class that produces the live `upstream_error` finish-chunk in the load-test-mock profile. Consolidate the LiteLLM call surface so all three LiteLLM-bound routes use one client.

Output: Refactored route + adapted/expanded test file + atomic commit ready for live re-probe by the operator.
</objective>
