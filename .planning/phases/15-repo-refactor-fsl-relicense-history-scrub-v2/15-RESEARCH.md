2. Post T-24h advisory issue
3. Lock branch protection on `main` via scripted `gh api`
4. Fresh-clone + `git filter-repo --path speaches-audio.md --invert-paths --force`
5. Sanity-check: commit-count delta + hash drift table
6. Force-push `main` (ONE force-push — PITFALLS §10)
7. Force-push surviving tags
8. GHA cache flush: UI clear + bump `CACHE_VERSION` env in workflows
9. Re-lock branch protection
10. Post T+15min advisory issue + update `MIGRATING.md` with new HEAD SHA + DCO bot cutoff SHA

**Note:** 15-04 is not a normal review-gated PR. It is a runbook execution event. The reviewable artifacts (`history-scrub.sh`, `history-scrub.test.sh`, `15-04-history-scrub.md`) get standard review; the force-push itself is a documented operational event.

- **R2: FSL codemod (15-03) and structural reorg (15-02) collide.** Mitigation: strict ordering 15-02 → 15-03 (codemod runs against final file paths from 15-02 moves).
- **R3: history scrub (15-04) invalidates open PRs.** Mitigation: T-24h advisory + T+15min advisory + recovery one-liners in MIGRATING.md and ADR.
- **R4: GHA cache mismatch post-scrub.** Mitigation: `CACHE_VERSION` env bump documented in runbook; workflows bumped in 15-03 to use the new key.
- **R5: signed-tag re-sign automation.** Mitigation: manual re-sign documented in runbook (DEFERRED automation).
- **R6: 15-01 ESLint rule false-positives.** Mitigation: rule's allow-list explicitly exempts `tools/load-test/`; tested as `no-co-located-test-files.test.ts` fixtures.
