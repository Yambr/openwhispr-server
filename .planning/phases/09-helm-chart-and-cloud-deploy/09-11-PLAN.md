<interfaces>
test-probe behavior (research §"Helm Test Hook"):
  1. Read env TARGET (https URL), SLO_DEADLINE_MS (default 300000)
  2. POST to /api/auth/sign-up with random email/password → expect 200, capture session token
  3. Sign in → capture bearer token
  4. POST to /api/transcribe with multipart 5s WAV (bundled fixture in image) and Bearer token → expect 200 with { id, text, ... }
  5. Compute elapsed-ms; emit structured JSON {"ok": true|false, "elapsedMs": N, "deadline": SLO_DEADLINE_MS}
  6. Exit 0 if ok and elapsed < deadline; nonzero otherwise
  7. NEVER log the bearer token or session token (T-09-04)

helm test hook (research §"Helm Test Hook" template body).

helm-upgrade-matrix.yml steps (research §"Upgrade-Matrix GHA Workflow"):
  1. checkout fetch-depth 0
  2. install CNPG via examples/cnpg-install.sh (helm repo add + helm install --wait)
  3. install Traefik with examples/traefik-values.yaml --wait
  4. install cert-manager --set crds.enabled=true --wait
  5. PREV=$(cat .chart-versions/previous) && git checkout $PREV -- charts/openwhispr
  6. helm install ow charts/openwhispr -f .github/ci/values-ci.yaml --wait --timeout 10m
  7. seed: kubectl exec deploy/ow-api -- node /app/tools/seed-test-data.js
  8. git checkout HEAD -- charts/openwhispr
  9. helm upgrade ow charts/openwhispr -f .github/ci/values-ci.yaml --wait --timeout 10m
  10. helm test ow --timeout 5m
  11. integrity: kubectl exec deploy/ow-api -- node /app/tools/integrity-check.js
  12. if: always() — kind delete cluster

helm-release.yml: helm/chart-releaser-action@v1.6+; on tag push v*.

.chart-versions/previous: plain text file containing exactly one chart version (e.g. `0.9.0-rc1`). The very first release seeds this manually via Task 6.
