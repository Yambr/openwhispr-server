  <behavior>
    - `makeSSRFDispatcher(opts)` returns a `new Agent({ connect: { lookup: ... } })` per RESEARCH.md §2
    - lookup function:
      1. Allow-list check: if hostname doesn't match any entry in `opts.allowedHosts` (with `*.wildcard` support), reject with `SSRFBlockedError('host_not_allowed', hostname)`
      2. `await dns.lookup(hostname, { all: true })` — single resolve
      3. For each resolved address: `checkBlocklist(address, family, opts)` returns rule name if blocked
      4. If hostname IS in `opts.privateHostAllowlist`, skip blocklist check (compose service names)
      5. If `opts.allowLoopback && NODE_ENV !== 'production'`, skip 127/8 + ::1/128 checks specifically
      6. If any blocklist rule matches AND mode==='enforce', reject; if mode==='warn', call onBlock+proceed
      7. Return first resolved address to undici via `cb(null, address, family)` — undici preserves URL hostname for `Host:` header and TLS SNI
    - SSRFBlockedError extends Error with `code: 'SSRF_BLOCKED'`, `rule`, `host`, `ip`
    - error-handler.ts: catches `SSRFBlockedError`, emits 502 `{error: 'Upstream blocked by SSRF policy', request_id}`, calls `recordAudit(tx, ctx, 'security.ssrf_blocked', {target_url_host: host, rule, mode})`
    - bootstrap.ts: parses env config, instantiates dispatcher, calls `setGlobalDispatcher(dispatcher)` — runs BEFORE `buildApp()` in index.ts
    - 12 CIDR checks implemented as a single `checkBlocklist` function with explicit ranges (NOT a regex; use `node:net.isIPv4`/`isIPv6` + numeric comparison or `ipaddr.js` lib)

    ```ts
    import { setGlobalDispatcher } from 'undici';
    import { makeSSRFDispatcher } from './lib/ssrf-dispatcher.js';
    import { loadSSRFConfig } from './config/ssrf.js';
    import { auditOnBlock } from './lib/audit.js';

    export function installGlobalSSRF() {
      const cfg = loadSSRFConfig();
      const dispatcher = makeSSRFDispatcher({
        allowedHosts: cfg.OUTBOUND_ALLOWED_HOSTS,
        privateHostAllowlist: cfg.OUTBOUND_PRIVATE_HOST_ALLOWLIST,
        allowLoopback: cfg.OUTBOUND_ALLOW_LOOPBACK,
        mode: cfg.OUTBOUND_SSRF_MODE,
        onBlock: ({ host, ip, rule }) => auditOnBlock({ host, ip, rule, mode: cfg.OUTBOUND_SSRF_MODE }),
      });
      setGlobalDispatcher(dispatcher);
    }
    ```
