## Operator H100 re-run contract

The realistic Mac baseline and the operator H100 plateau share the
exact same TypeScript source. The operator changes only:

```sh
# .env (operator-supplied)
HF_TOKEN=hf_...
OPENROUTER_API_KEY=sk-or-...
OPENAI_API_KEY=sk-...

# H100 plateau via env override
BASELINE_VUS=1000 BASELINE_DURATION_SUSTAIN=20m \
  tools/load-test/scripts/baseline.sh
```

No bundle rebuild, no code touch, no plan change. `buildOptions(__ENV)`
reads `BASELINE_VUS` + `BASELINE_DURATION_*` and produces the H100
scenario shape (5m → 1000 / 20m @ 1000 / 2m → 0).
