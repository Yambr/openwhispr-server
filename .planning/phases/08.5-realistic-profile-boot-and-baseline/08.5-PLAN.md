# Phase 08.5 — Realistic Profile Boot + Mac Baseline (Umbrella)

## Goal

Boot `load-test-realistic` end-to-end on the developer Mac with Speaches +
Whisper-large-v3 + pyannote behind a REAL LiteLLM proxy (per
`/Users/dev/openwhispr-server/speaches-audio.md`), run the existing k6 smoke
gate (5 VU × 60 s, ZERO TypeError / ZERO ws-zero-frames) and a short Mac
baseline (100 VU × 12 min = 5 + 5 + 2) producing a coherent summary JSON.
**The wiring is the deliverable; the numbers are advisory until the operator
re-runs on H100 by swapping `.env` provider keys + bumping `BASELINE_VUS`.**

## Goal-Backward — Must-Haves

### Observable Truths

1. `make load-test PROFILE=realistic` brings every container (postgres, pgbouncer, valkey, traefik, api, **real LiteLLM**, speaches) to healthy on a fresh Mac.
2. `docker compose --profile load-test-realistic config` resolves `services.litellm.image` to `ghcr.io/berriai/litellm:main-v1.83.14-stable` (NOT `openwhispr-mock-litellm:dev`) and mounts `litellm_config.realistic.yaml`.
3. Speaches preloads `Systran/faster-whisper-large-v3` and `pyannote/speaker-diarization-community-1` at boot (via `PRELOAD_MODELS`), with HF cache persisted at `/home/ubuntu/.cache/huggingface` across `down + up`.
4. Pre-warm script in `--strict` mode (default-on under realistic profile) exits non-zero if any preloaded model is not ready after N seconds.
5. The k6 smoke gate passes against the realistic stack at 5 VU × 60 s with zero TypeError, zero `Cannot assign to property`, zero ws-zero-frames.
6. The 100-VU × 12-min `baseline.ts` scenario runs to completion and writes `runs/<stamp>-realistic-mac.json` + `<stamp>-realistic-mac-summary.json` with non-zero p95 numbers for all four flows (transcribe, reason, agent-stream, realtime-ws).
7. Every existing vitest + k6 file is byte-identical except the deliberate extensions in this phase — operator H100 re-run uses the SAME suite, only `.env` + `BASELINE_VUS` env change.
8. `docs/operations.md` distinguishes Mac-bound metrics (transcribe — CPU-bound) from architecture-bound metrics (reason / agent-stream / realtime-ws — network-bound to public APIs) with `OPERATOR_RERUN_ON_GPU` markers.

### Key Links

- `run.sh realistic` → layers `-f docker-compose.yml -f docker-compose.load-test.yml -f docker-compose.load-test.realistic.yml`. Without the third file the mock overlay wins and Speaches is dead code.
- `litellm_config.realistic.yaml` → mounted into the real LiteLLM container ONLY under the realistic overlay. Bundled `litellm_config.yaml` stays untouched (corporate-LiteLLM-ready by env override remains intact).
- `baseline.ts` → reads `BASELINE_VUS` and `BASELINE_DURATION` from `__ENV`; defaults are Mac-safe (100 / 12m). Operator on H100 sets these in `.env` and the same bundle runs at 1000 VU × 30 min.
- `pre-warm-speaches.sh --strict` → checks `/v1/audio/transcriptions` warm path AND `ls /home/ubuntu/.cache/huggingface/hub/` returns the expected model dirs. Mac smoke depends on this; without it iter-0 cold-start pollutes p95.

## Threat Model

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08.5-01 | Information disclosure | `HF_TOKEN` (pyannote gated weights) | mitigate | `.env.example` documents it as required env, NEVER committed; compose passes via `${HF_TOKEN:-}`; pre-warm-speaches.sh checks env existence and warns (not logs the value) when absent |
| T-08.5-02 | Information disclosure | `OPENAI_API_KEY` / `OPENROUTER_API_KEY` (provider keys, used for /v1/realtime + /api/reason + /api/agent/stream in realistic profile) | mitigate | Already env-driven; documented in `.env.example`; preflight.sh adds soft-warn when realistic + missing keys |
| T-08.5-03 | Spoofing | Whisper model cache provenance (HF model weights ~3 GB auto-downloaded at boot) | accept | HF model IDs pinned by name (`Systran/faster-whisper-large-v3`, `pyannote/speaker-diarization-community-1`); HF Hub TLS provides integrity; corporate override path documented separately for air-gapped deploys (out of scope for Mac baseline) |
| T-08.5-04 | Tampering | `litellm_config.realistic.yaml` mount path / contents | mitigate | Read-only volume mount in the overlay (`:ro`); vitest + lint-style test asserts file shape; no `master_key` material in the YAML (sourced from env) |
| T-08.5-05 | Denial of service | Mac OOM under 100 VU × 12 min — Speaches + postgres + 4 pgbouncer + valkey + grafana + tempo + mimir + traefik + api + litellm + speaches (~12–16 GB) | accept | RESEARCH §P4 documents Docker Desktop 16 GB requirement; `docs/operations.md` adds operator note; not a security issue, an operational one |
| T-08.5-06 | Repudiation | Run artifacts under `runs/` are operator-authored, not signed | accept | Committed to git → git history is the audit trail; consistent with Phase 08 runs/ pattern |

## Deferred Items (OUT OF SCOPE)

- **H100 baseline re-run** — operator-driven, off-Mac. Plan 08.5-03 prepares `OPERATOR_RERUN_ON_GPU` markers but does not execute.
- **1000 VU on Mac** — would saturate Whisper queue + OOM Speaches (RESEARCH §P4 / Mac feasibility).
- **Diarization in Mac smoke** — adds 30+ s cold start, requires HF_TOKEN, and bundled api routes diarization through pyannote.ai cloud anyway (D-07 REVISED). Skipped per RESEARCH §G7 / §3 recommendation.
- **Speaches realtime endpoint** — Mac CPU realtime is too slow; realistic profile keeps `gpt-realtime → OpenAI Realtime direct` (RESEARCH §P9).
- **SLO publication of Mac numbers** — Mac numbers are advisory; SLO publication waits for H100 re-run.
- **Mimir SLO dashboards for realistic** — premature without H100 data (Deferred Idea per RESEARCH §User Constraints).
- **GitHub Actions CI for baseline runs** — operator-driven local runs by design (RESEARCH §Project Constraints). Unit + shell tests for the new pieces DO run in CI (extend existing `load-test` workflow).
- **CI run of the live realistic stack** — same reason; HF_TOKEN / OPENAI_API_KEY not in CI secrets, by design.
