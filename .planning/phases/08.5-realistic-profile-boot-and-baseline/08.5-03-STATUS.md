# Phase 08.5 Plan 03 — Live boot status

**STATUS: BLOCKED on authentication gates. Operator action required.**

Plan 08.5-03 executes the live realistic-stack bring-up, k6 smoke gate,
and 100 VU × 12-min Mac baseline. All three tasks depend on operator-
supplied API keys in `.env` that are currently absent:

| Key | Purpose | Failure mode if missing |
|-----|---------|-------------------------|
| `HF_TOKEN` | pyannote-3.1 + community-1 gated HF weight download (~1.5 GB) | Speaches container boot fails the pyannote model preload with HF 403; pre-warm-speaches.sh `--strict` aborts the run when the pyannote model dir is absent from the HF cache (08.5-01 Task 4). |
| `OPENROUTER_API_KEY` | k6 reason flow + agent-stream flow upstream | LiteLLM returns 503 for both /api/reason and /api/agent/stream — smoke gate fails on `http_req_failed` ceiling. |
| `OPENAI_API_KEY` | k6 realtime-ws flow (/v1/realtime upstream) | LiteLLM realtime alias returns close-with-error on WS upgrade — smoke gate fails on ws_msgs_received == 0 (Phase 08.4 regression class). |

`.env` currently has all three set to placeholder / empty values
(`PLACEHOLDER_BOOTSTRAP_WILL_REPLACE` or blank). The bundled
`bootstrap.sh` does NOT auto-generate provider keys — they are
operator-supplied per `.env.example` and per Phase 03's policy
(operators paste their own).

## Operator unblock recipe

1. Populate `.env`:
   ```sh
   HF_TOKEN=hf_...   # https://huggingface.co/settings/tokens (read scope; accept pyannote model gates)
   OPENROUTER_API_KEY=sk-or-...
   OPENAI_API_KEY=sk-...
   ```
2. Confirm Docker Desktop memory ≥ 16 GB (RESEARCH §P4). Mac has 35.18 GiB, so OK.
3. First-time bring-up (downloads ~3 GB of HF weights — Whisper-large-v3 + pyannote-community-1):
   ```sh
   make load-test PROFILE=realistic   # runs run.sh realistic → boot + smoke gate
   ```
   Expected wall-clock: 10–15 min on first boot (mostly model download).
   If `docker compose up --wait` times out on the 600s healthcheck buffer,
   re-run — the second boot finds the weights cached in the named volume.
4. After run.sh exits 0 (smoke PASS), run the baseline against the
   still-running stack:
   ```sh
   OPENWHISPR_LOADTEST_REUSE_STACK=1 \
     tools/load-test/scripts/baseline.sh
   ```
   Outputs land at:
   - `.planning/phases/08.5-realistic-profile-boot-and-baseline/runs/<stamp>-realistic-mac.json`
   - `…/runs/<stamp>-realistic-mac-summary.json`
5. Commit the run artifacts + write `runs/RUN-LOG.md` per Plan 08.5-03
   Task 3 template; extend `docs/operations.md` with the
   `OPERATOR_RERUN_ON_GPU` markers per Plan 08.5-03 Task 3 action block.
