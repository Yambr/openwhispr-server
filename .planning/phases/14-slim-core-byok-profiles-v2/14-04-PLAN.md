  readonly event: "byok.required";
  readonly code: BYOKErrorCode;

 */

The guard does NOT try to probe the network to see if `minio` resolves; that would re-introduce the cascading-noise problem CONTEXT.md decision 2 warned against. The matrix collapses to: "for each row, if `missing` envs are unset (and NODE_ENV gate satisfied for SMTP), emit fatal + exit 1."

    - Any URL substring in the hint that contains credentials is run through `redactUrl()`.
    - If multiple overlays are misconfigured simultaneously, emit ONE fatal record covering the FIRST violation in matrix order (storage → observability → ingress → pgbouncer → dev-tools) and exit. (Operators fix one at a time; multi-fatal noise is anti-pattern.)
