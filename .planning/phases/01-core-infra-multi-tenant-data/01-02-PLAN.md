<objective>
Ship the refuse-to-start gate at two layers: the operator-side `tools/bootstrap.sh` (idempotent secret generator + deny-list rejector) AND the runtime-side `apps/api/scripts/check-default-secrets.ts` (defense-in-depth check at container entrypoint). Drive both via a constitutional self-test (`tests/self-tests/refuse-default-secrets.test.ts`) that mirrors the Phase 0 self-test pattern (`tests/self-tests/cyrillic-injection.test.ts`).

Purpose: Phase 1 success criterion #1 — "the runtime aborts on any known-default value like `changeme` or `sk-1234`." Without this gate, an operator who forgets to run bootstrap (or whose CI pipeline skips it) ships shipping-default secrets to prod. Two-layer defense catches both bypass paths.

Output: A repository where `bash tools/bootstrap.sh` from a clean clone with no `.env` produces a valid `.env` with strong random values, refuses to overwrite operator-set secrets, and the API container refuses to boot if any required env var is unset or deny-listed.
</objective>

    #!/usr/bin/env node
    import { readFileSync } from "node:fs";
    import { resolve } from "node:path";

    const denyPath = resolve(
      process.env.DENY_LIST_PATH ??
        new URL("../../tools/bootstrap/default-secrets.txt", import.meta.url).pathname,
    );
    const deny = readFileSync(denyPath, "utf8")
      .split("\n").map(l => l.trim()).filter(l => l && !l.startsWith("#"));

    const REQUIRED_KEYS = [
      "POSTGRES_OWNER_PASSWORD",
      "POSTGRES_APP_PASSWORD",
      "PGBOUNCER_ADMIN_PASSWORD",
      "VALKEY_PASSWORD",
      "MINIO_ROOT_PASSWORD",

      "GRAFANA_ADMIN_PASSWORD",
      "MASTER_KEK",
      "BACKUP_AGE_IDENTITY",
      "BETTER_AUTH_SECRET",
    ];

    const offenders: string[] = [];
    for (const k of REQUIRED_KEYS) {
      const v = process.env[k];
      if (!v || deny.includes(v)) offenders.push(k);
    }
    if (offenders.length > 0) {
      for (const k of offenders) {

      process.exit(1);
    }
