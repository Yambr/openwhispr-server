## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03-01 | Information Disclosure | Cross-tenant leak via missing RLS on a new table | mitigate | ENABLE+FORCE on every tenant_id table; Plan 05 lint blocks future regressions |
| T-01-03-02 | Elevation of Privilege | _app role inherits BYPASSRLS via accidental GRANT | mitigate | Two independent roles, no GRANT role TO role; init script DO-block raises if BYPASSRLS observed on _app |
| T-01-03-03 | Information Disclosure | _app connects without setting app.tenant_id, reads all rows | mitigate | current_setting('app.tenant_id', true)::uuid fails closed: empty -> cast fails -> policy denies |
| T-01-03-04 | Tampering | Migration runner connects via PgBouncer (transaction-pool reuse + BYPASSRLS = leak vector) | mitigate | makeOwnerDb requires DATABASE_URL_OWNER (port 5432, direct); throws if env unset |
