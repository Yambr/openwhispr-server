## D-05 implementation notes

`findStalePathLiterals(rootDir)` uses `ts.createSourceFile` + a node
visitor to detect static path literals resolving to non-existent
siblings. Shapes flagged:

- `readFileSync|readFile|existsSync|statSync( path.resolve|path.join( __dirname, "<StringLiteral>" ) )`
- `new URL("<relative StringLiteral>", import.meta.url)`

Template literals and identifier args are intentionally skipped
(false-positive suppression > recall for a regression guard). Repo
currently reports `clean` after Wave-1 repointing.

Zero new top-level deps (D-44 honored) — uses the already-resolvable
`typescript` package.
