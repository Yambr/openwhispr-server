## D-39 implementation notes

`findAwaitInNonAsync(rootDir)` walks all `*.test.ts` / `*.ts` files,
parses each via `ts.createSourceFile`, visits `AwaitExpression` nodes,
and walks parent chain to find the nearest function-scope ancestor
(FunctionDeclaration / FunctionExpression / ArrowFunction / Method /
Get/SetAccessor / Constructor). Reports the await iff that scope's
modifiers do NOT include `AsyncKeyword`. Top-level await (no enclosing
function) is allowed — used by the `REACHABLE = await probeBackend()`
guard.
