2. **Add primitives** — single command:
   ```bash
   pnpm dlx shadcn@latest add \
     alert alert-dialog badge button card dropdown-menu form input \
     label scroll-area separator sheet skeleton table tabs tooltip sonner
   ```
   All 17 (16 + sonner) primitives must land under `apps/web/src/components/ui/`.
3. **Verify `apps/web/src/lib/utils.ts`** exists and exports `cn(...inputs: ClassValue[])` from clsx + tailwind-merge. shadcn init emits this; do not overwrite.
4. **Tailwind 4 compatibility sweep** — open each primitive file and confirm:
   - No `@apply` references that depend on Tailwind 3 plugin names.
   - Class names already use the standard utility set (`bg-background`, `text-foreground`, etc.) — these resolve against the shadcn-managed `:root` block injected into `globals.css` by `init`. If `init` did NOT inject the shadcn `:root` variables alongside the Appendix A `@theme`, manually merge them: keep BOTH the Appendix A `@theme { --color-*: ... }` block AND the shadcn-generated `--background / --foreground / --primary / --primary-foreground / --muted / --muted-foreground / --accent / --accent-foreground / --destructive / --destructive-foreground / --border / --input / --ring / --radius` variables. Map shadcn aliases to Appendix A tokens via `@layer base` (e.g., `--background: var(--color-bg)`).
5. **Typecheck gate** — run `pnpm --filter @openwhispr/web typecheck`. MUST exit 0. If a primitive file fails typecheck (occasional shadcn/React 19 mismatch), patch the import (typical fix: replace deprecated `React.FC` with explicit prop types) and commit the fix. Do NOT silence with `@ts-ignore`.
6. **Sonner wire-in** — add `<Toaster />` import + render inside `apps/web/src/app/layout.tsx` body (top-level, after `{children}`); import comes from `@/components/ui/sonner`. This makes toast available globally; consumers will call `import { toast } from 'sonner';`.
