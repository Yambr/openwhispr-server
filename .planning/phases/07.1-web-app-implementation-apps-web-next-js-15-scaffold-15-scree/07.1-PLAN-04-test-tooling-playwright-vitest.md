```bash

   apps/api/src/routes/conversations/ \
   apps/api/src/routes/folders/
```

Then read each candidate route file to confirm the following endpoints are implemented:
- (a) `POST /api/notes/create` — likely `apps/api/src/routes/notes/create.ts`
- (b) `POST /api/transcriptions/create` (or `batch-create`) — likely `apps/api/src/routes/transcriptions/create.ts` or `batch-create.ts`
- (c) `POST /api/conversations/create` — likely `apps/api/src/routes/conversations/create.ts`
- (d) `POST /api/folders/create` — likely `apps/api/src/routes/folders/create.ts`
- (e) `DELETE /api/notes/delete-all` — likely `apps/api/src/routes/notes/delete-all.ts`

For each route file found, open it and confirm: HTTP method, path, request body shape (cross-reference `packages/wire-schemas/`), success status code, auth requirement.

**Document the verification result in the commit body of the seed.ts commit under `## Seed endpoint inventory` — one line per endpoint with status `PRESENT (file: ...)` or `MISSING`.**

For any endpoint that is MISSING, the executor MUST pick and document an alternative seed strategy in the seed.ts source as a top-of-file comment AND in the commit body. The three sanctioned alternatives, in preference order, are:

1. **Direct Postgres insert via `@openwhispr/data`** — import the Drizzle schema, open a connection with the test DB credentials from compose, INSERT the rows directly. Use this when the resource is read-mostly and an API create path simply doesn't exist.
2. **Per-row delete via list+iterate** — replace a missing `delete-all` endpoint by `GET /api/<resource>/list` → iterate the result and call the per-row `DELETE /api/<resource>/delete?id=<id>` for each. Use this when only the bulk-delete is missing.
3. **Skip-and-seed-via-API-equivalent** — if a different endpoint produces the same row shape (e.g. `POST /api/transcriptions/batch-create` accepts `[CloudTranscription]` and equally satisfies the seed need), use that endpoint and document the substitution.

The seed fixture MUST be **runnable end-to-end before any e2e plan (07+) starts**. To prove this, after writing `seed.ts` run:

