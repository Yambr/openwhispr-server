## Notable deviations from plan

1. **Env-switch escape hatches added** (Rule 2: needed for deterministic test mode). All default-OFF in prod:
   - `PLAYWRIGHT_DISABLE_SSR_PREFETCH` — disables RSC prefetch in Playwright runs that hit auth-pinned routes (mitigates better-auth#7008-class prefetch races).
   - `OPENWHISPR_DISABLE_EMAIL_ENUMERATION_PROTECTION` — sign-up duplicate-email feedback (apps/api preHandler), needed for the u2 dup-email assertion; **production default keeps enumeration protection ON**.
   - `OPENWHISPR_DISABLE_SESSION_COOKIE_CACHE` — disables better-auth in-process session.cookieCache during e2e to avoid stale-cookie races; prod keeps cache on.
2. **Mailpit moved into default compose profile** (Rule 3: blocking). Sign-up verification email round-trip needs an SMTP sink; mailpit was previously dev-profile only.
3. **apps/api preHandler for `/api/auth/sign-up/email`** (config, NOT new endpoint per D-S1). Adds duplicate-email rejection BEFORE Better Auth's silent dedup (which always returns 200 for security). Behind the env switch above.
4. **Branch B for U7 transcription detail.** No `GET /api/transcriptions/:id` endpoint exists; Plan 09 Step 0 confirmed and adopted list-then-filter with `limit=50` × `MAX_PAGES=5` cap. Backlog item recorded for Phase 7.x.
5. **Worker-scoped Playwright fixtures** (Rule 1 fix during Plan 13 follow-up, commit 36c87f3). One provisioned user per Playwright worker, not per test — eliminates Better Auth per-IP rate-limit thrashing in the full e2e run.
6. **DEF-07.1-NOTES-DELETE-ALL** (pre-existing apps/api bug, OPEN). `DELETE /api/notes/delete-all` returns 500; mitigated client-side by per-row delete fallback in seed fixture. Tracked in `deferred-items.md`.
7. **DEF-07.1-01 lru-cache CJS/ESM mismatch** (RESOLVED). pnpm-workspace `overrides.lru-cache: ^11.3.6` forced re-resolution.
