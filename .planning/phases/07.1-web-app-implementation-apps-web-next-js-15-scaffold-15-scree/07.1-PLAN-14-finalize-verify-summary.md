Steps:

1. **Full sweep** — execute and capture output:
   ```bash
   pnpm install --frozen-lockfile
   pnpm --filter @openwhispr/web typecheck
   pnpm exec biome check apps/web/
   pnpm --filter @openwhispr/web test --coverage
   pnpm --filter @openwhispr/web build
   pnpm --filter @openwhispr/web exec size-limit
   pnpm --filter @openwhispr/web exec playwright test
   ```
   All MUST exit 0. Coverage report MUST show ≥90/90/90/90 on lines/branches/functions/statements for the diff touchset.

2. **Negative-constraint audit** — run these greps from repo root and confirm zero matches:
   ```bash
   # No emojis in source (Unicode > U+1F300 range)
   rg -P "[\x{1F300}-\x{1FAFF}]" apps/web/src/ && echo FAIL || echo OK
   # No localStorage token storage (D-SEC-2). Theme preference is allowed.
   rg "localStorage\\.(setItem|getItem)\\([\"']?(token|bearer|auth|session)" apps/web/src/ && echo FAIL || echo OK
   # No next-i18next
   rg "next-i18next" apps/web/ && echo FAIL || echo OK
   # No ESLint
   rg "eslint" apps/web/package.json && echo FAIL || echo OK
   # No Recharts
   rg "recharts" apps/web/ && echo FAIL || echo OK
   # No app-level admin role check
   rg "role.*===.*['\"]admin['\"]" apps/web/src/app/\(admin\)/ && echo FAIL || echo OK
   # No raw token rendering on verify-email
   rg "params\\.token|searchParams\\.token" apps/web/src/components/screens/auth/VerifyEmailClient.tsx | grep -v "TokenSchema\\|validated" && echo FAIL || echo OK
   ```
   Each command MUST print OK (zero matches). Document any deviation in SUMMARY.md.
