Steps:
1. **Write `apps/web/Dockerfile`** verbatim from RESEARCH § Code Examples → Dockerfile block. Three stages (deps / build / runner) on `node:24-alpine`. `corepack enable pnpm` in each stage that needs pnpm. Final stage copies `.next/standalone`, `.next/static`, `public/`, runs as non-root `nextjs:nodejs` (uid 1001), exposes 3000, HEALTHCHECK probes `/api/health` via `wget --spider`, CMD `["node", "apps/web/server.js"]`.
2. **Write `apps/web/.dockerignore`**: `node_modules`, `.next`, `coverage`, `playwright-report`, `test-results`, `.env*`, `.git`, `tests/e2e` (e2e specs not needed in image), `*.md`.
3. **Patch `compose/traefik/traefik.yml`** providers block to add `docker` alongside `file`:
   ```yaml
   providers:
     file:
       filename: /etc/traefik/dynamic.yml
       watch: true
     docker:
       exposedByDefault: false
       network: openwhispr_internal
   ```
   Mount `/var/run/docker.sock:/var/run/docker.sock:ro` on the Traefik service in `docker-compose.yml`.
4. **Add `web` service to `docker-compose.yml`** verbatim from RESEARCH § Code Examples → `web` service block. Critical fields:
   - `build.context: .` and `dockerfile: apps/web/Dockerfile`
   - `profiles: [default]`
   - `networks: [openwhispr_internal]`
   - `env_file: .env`
   - `environment`: `NODE_ENV=production`, `INTERNAL_API_URL=http://api:3000`, `NEXT_PUBLIC_GRAFANA_BASE_URL=${NEXT_PUBLIC_GRAFANA_BASE_URL:-}`, `NEXT_PUBLIC_TEMPO_BASE_URL`, `NEXT_PUBLIC_MIMIR_BASE_URL`, `NEXT_PUBLIC_LOKI_BASE_URL`, `NEXT_PUBLIC_OIDC_PROVIDERS=${NEXT_PUBLIC_OIDC_PROVIDERS:-google,github,oidc}`
   - `depends_on: { api: { condition: service_healthy } }`
   - `healthcheck`: wget `/api/health`, 10s interval, 30s start_period
   - `restart: unless-stopped`
   - `labels` (Traefik): full set from RESEARCH including `web` router (priority 1, PathPrefix `/`) AND `web-admin` router (priority 100, PathPrefix `/admin`, middlewares=admin-basicauth@docker) AND the `admin-basicauth` middleware definition `traefik.http.middlewares.admin-basicauth.basicauth.users=${ADMIN_BASIC_AUTH_USERS}` AND `traefik.http.services.web-svc.loadbalancer.server.port=3000`
5. **Update `.env.example`** (repo root) — append a `# Phase 07.1 web app` section with:
   ```
   # Comma-separated htpasswd-format entries: user:$apr1$... OR user:$2y$05$...
   # Generate with: htpasswd -nbB admin "<plaintext-password>"  (bcrypt, recommended)
   # Per D-ADMIN-2: convention is first-registered-user-email-derived basic-auth, but
   # no code path enforces it — operators choose the credential.
   ADMIN_BASIC_AUTH_USERS=

   # Observability deep-links for /admin/observability (A2)
   NEXT_PUBLIC_GRAFANA_BASE_URL=
   NEXT_PUBLIC_TEMPO_BASE_URL=
   NEXT_PUBLIC_MIMIR_BASE_URL=
   NEXT_PUBLIC_LOKI_BASE_URL=

   # OIDC providers shown on sign-in / sign-up (controls button visibility only;
   # actual OIDC config lives in apps/api env vars per Phase 2 PROVIDER-03)
   NEXT_PUBLIC_OIDC_PROVIDERS=google,github,oidc
   ```
6. **Bootstrap validation (executor-run, autonomous)** — executor runs the following four probes and records the HTTP status code AND the curl exit code of each one in the commit body under a `## Verification` heading. If any probe returns an unexpected status, debug and re-run before committing — do NOT commit a half-working stack.

   ```bash
   ADMIN_BASIC_AUTH_USERS="$(htpasswd -nbB admin testpw123 | sed 's/\$/\$\$/g')" \
   docker compose --profile default up -d --build --wait

   # Probe 1 — api still wins for /api/*
   curl -fsSk -o /dev/null -w 'probe1 http=%{http_code} exit=$?\n' https://api.localhost/api/health

   # Probe 2 — web 200 at root
   curl -fsSk -o /dev/null -w 'probe2 http=%{http_code} exit=$?\n' https://api.localhost/

   # Probe 3 — admin gate denies without basic-auth
   curl -sk -o /dev/null -w 'probe3 http=%{http_code} exit=$?\n' https://api.localhost/admin/observability

   # Probe 4 — admin gate accepts with valid basic-auth
   curl -fsSk -u admin:testpw123 -o /dev/null -w 'probe4 http=%{http_code} exit=$?\n' https://api.localhost/admin/observability
   ```

   Expected outcomes:
   - probe1: `http=200 exit=0`
   - probe2: `http=200 exit=0`
   - probe3: `http=401` (`exit` will be non-zero on `-f` so omit `-f` for probe 3, as shown above)
   - probe4: `http=200 exit=0` (page body may be Next.js 404 if Plan 12 not yet executed — what matters is the 200 from the basic-auth gate; the page itself materializes in Plan 12)

   The commit body MUST contain a `## Verification` heading reproducing the four lines above with actual numbers substituted in. If any line deviates, debug (`docker compose logs traefik | grep -i basicauth`, check `$` escaping in `.env`, verify middleware label spelling) and re-run before committing.

   IMPORTANT: in `.env` (not `.env.example`), `$` characters from bcrypt MUST be escaped as `$$` for compose interpolation. Document this in `.env.example` as a comment.

Constraints:

- Do NOT publish port 3000 of the web service to the host — Traefik handles ingress.
- Do NOT bake `ADMIN_BASIC_AUTH_USERS` into the image — it's runtime env.
