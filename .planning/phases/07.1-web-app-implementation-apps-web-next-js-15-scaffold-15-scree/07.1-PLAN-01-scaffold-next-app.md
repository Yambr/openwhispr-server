<task>
Create the bare Next.js 15 + Tailwind 4 + TS strict scaffold under apps/web/, wire security headers and standalone output, ship a /api/health route, transcribe Appendix A tokens to globals.css. Acceptance:
- `pnpm install` followed by `pnpm --filter @openwhispr/web typecheck` exits 0.
- `pnpm --filter @openwhispr/web build` produces `apps/web/.next/standalone/apps/web/server.js`.
- Manual curl smoke (executor performs locally): `node apps/web/.next/standalone/apps/web/server.js & sleep 2; curl -fsS http://localhost:3000/api/health` returns body `OK` and 200.
- Header inventory verified by `curl -sI http://localhost:3000/` includes all five COMMON_HEADERS plus a CSP; `curl -sI http://localhost:3000/sign-in` shows the STRICT_AUTH_CSP variant (executor adds a temporary `app/(public)/sign-in/page.tsx` stub returning a basic <main>Hello sign-in</main> ONLY for this validation — leave the stub file in place; Plan 07 will overwrite it).

Step order:
1. **Install scaffold** — from repo root run `pnpm dlx create-next-app@15 apps/web --ts --tailwind --eslint --app --src-dir --import-alias "@/*" --use-pnpm --no-experimental-app --skip-install`. Then delete the ESLint config files (`apps/web/.eslintrc.json`, `apps/web/eslint.config.mjs` — whichever was emitted) — repo uses Biome (CLAUDE.md "no ESLint conflict"). Strip `eslint` and `eslint-config-next` from `apps/web/package.json` devDependencies.
2. **Patch `apps/web/package.json`**: `name: "@openwhispr/web"`, `private: true`, scripts: `dev`, `build`, `start`, `typecheck: "tsc --noEmit"`. Add deps per RESEARCH § Standard Stack install command (next@15, react@19, react-dom@19 only here; auth/query/forms/i18n land in Plan 05/06; shadcn deps land in Plan 02). Add devDeps: typescript@5, @types/react, @types/react-dom, @types/node, tailwindcss@4, @tailwindcss/postcss, postcss.
3. **Patch `apps/web/tsconfig.json`**: extend strict — mirror `apps/api/tsconfig.json` strictness flags exactly (`strict`, `noUncheckedIndexedAccess`, `noImplicitOverride`, `noFallthroughCasesInSwitch`). Path alias `"@/*": ["./src/*"]`.
4. **Write `apps/web/next.config.ts`** verbatim from RESEARCH § Code Examples → `next.config.ts` block. Critical fields: `output: 'standalone'`, `outputFileTracingRoot: path.join(__dirname, '../../')` (Pitfall 10), `reactStrictMode: true`, `poweredByHeader: false`, `experimental: { typedRoutes: true }`, `async headers()` returning the STRICT_AUTH_CSP for `/sign-in`, `/sign-up`, `/verify-email` and the APP_CSP for `/:path*`. Include `@next/bundle-analyzer` wrapping (gated by `process.env.ANALYZE === 'true'`).
5. **Write `apps/web/src/app/globals.css`**: `@import "tailwindcss";` followed by the `@theme` block transcribed verbatim from UI-SPEC Appendix A (light theme color roles, dark theme override under `[data-theme="dark"]`, typography ramp, radius, spacing). Include the `color-mix` @layer base hack for `--color-accent-soft` per RESEARCH § Pattern 8.
6. **Write `apps/web/postcss.config.mjs`** for Tailwind 4: `export default { plugins: { '@tailwindcss/postcss': {} } };`.
7. **Write `apps/web/src/app/layout.tsx`** — minimal root: `<html lang="en"><body>{children}</body></html>`. Import `./globals.css` at the top. Add `export const metadata = { title: 'OpenWhispr', description: 'OpenWhispr Server web console' };`. Providers come from Plan 06; leave a TODO comment.
8. **Write `apps/web/src/app/api/health/route.ts`**: `export const dynamic = 'force-dynamic'; export function GET() { return new Response('OK', { status: 200 }); }`.
9. **Write `apps/web/.env.example`** documenting: `INTERNAL_API_URL=http://api:3000`, `NEXT_PUBLIC_GRAFANA_BASE_URL=`, `NEXT_PUBLIC_TEMPO_BASE_URL=`, `NEXT_PUBLIC_MIMIR_BASE_URL=`, `NEXT_PUBLIC_LOKI_BASE_URL=`, `NEXT_PUBLIC_OIDC_PROVIDERS=google,github,oidc`. Each line gets a one-line comment in English.
10. **Update root `.gitignore`** to ignore `apps/web/.next`, `apps/web/coverage`, `apps/web/playwright-report`, `apps/web/test-results`, `apps/web/node_modules`.
11. **Verify `pnpm-workspace.yaml`** already lists `apps/*` (per CONTEXT D-STRUCT-2). If not, add it — but expect no change.
12. **Lockfile** — from repo root run `pnpm install` to update `pnpm-lock.yaml` and link the new workspace.
13. **Validation gate**: run `pnpm --filter @openwhispr/web typecheck` + `pnpm --filter @openwhispr/web build`. Both MUST exit 0. Probe `/api/health` per Acceptance bullet above.
