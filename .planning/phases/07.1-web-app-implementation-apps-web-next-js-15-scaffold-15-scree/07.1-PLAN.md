## TDD Discipline

Every plan in waves 1–3 follows the constitutional cycle:
- **RED commit** `test(07.1-NN): add failing test for <slice>` — tests committed first; CI shows them failing
- **GREEN commit** `feat(07.1-NN): implement <slice>` — production code lands together with test fixes, suite goes green
- **REFACTOR commit** (optional) `refactor(07.1-NN): clean up <slice>` — no behavior change, tests still green

Wave 0 plans land scaffolding via `chore(07.1-NN): ...`; their tests come from Plan 04 fixtures.
